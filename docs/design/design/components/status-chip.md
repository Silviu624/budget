# Status chip

A pill that names a month's state or a movement's type.

- Month: `Planificată` (`surface-sunken`, `ink-muted`, hollow dot) while the month is editable; `Aplicată` (`accent-soft`, `accent`, check icon) after „Aplică luna”.
- Movement types: `Contribuție`, `Retragere`, `Sold inițial` — neutral chips with an arrow icon; the amount beside them carries the colour.
- Height 26px, radius `radius-full`, text `label`.
