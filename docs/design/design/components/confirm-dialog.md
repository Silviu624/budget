# Confirm dialog

Asks before an action that changes balances or removes data: „Aplică luna”, deleting a category or a fixed expense.

- Title as a question („Aplici luna Octombrie 2026?”), one sentence of consequence that names the amount, then „Anulează” (secondary) and „Confirmă” (primary).
- `surface`, `radius-xl`, `shadow-lg`, over `scrim`. Width 360px; on mobile a bottom sheet with the same content.
