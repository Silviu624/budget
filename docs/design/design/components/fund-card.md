# Fund card

A saving bucket at a glance on Fonduri; spending buckets use a single row instead.

- **Provide**: name, balance (Sold), optional target, this month's contribution, optional overflow target and any surplus received.
- Header: kind icon (`accent-soft` vault), name in `title-3`, chevron — the whole card opens the bucket detail.
- Balance right-aligned in `amount-lg`; target progress; footer with „Contribuție Octombrie · planificată” as a positive amount, and the overflow note „Surplusul merge către …” with a corner-arrow icon.
- Spending buckets („Buget de cheltuieli”): wallet icon on `surface-sunken`, „10% din rămas · fără sold”, allowance on the right.
